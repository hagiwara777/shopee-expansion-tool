# FROMAXとの併用

本ツールはFROMAXへ入れる前のリサーチ・安全確認を担当する（DEC-0159／0160）。
大量収集はFROMAXのKeepaリサーチ、Shopeeで売れる商品からのASIN特定は本ツールのResolverを主力にする。
カテゴリ・brand・属性・価格・出品・在庫管理はFROMAXに任せ、Expansionの既存機能は保全する。

## SGの候補・安全資料

SGの保安ゲートには、候補CSV、そのCSVと一緒に出力した成分資料・説明文資料、全ショップの既出品CSVを指定する。
候補と資料のASIN・内容が対応しない場合、資料を省略した場合は判定を実行しない。
候補や資料を変更・削除すると前の判定・出力を失効させる。
個別の成分が欠損していても、欠損記録を含む正しい資料ファイルなら受け付け、その欠損だけではREVIEWにしない。
Expansionの一式内部引継ぎも既存の対応検証を使う。PHの画像確認や既存の停止条件は維持する。

FROMAXのASINを比較する際は、ASINをAmazon JPのURL表記にして既存Resolverの確認処理へ渡せる。
この方法はASINの実在確認・候補CSV・成分／説明文資料を再利用し、新しいFROMAX CSV専用取込を必要としない。
処理関数での実資料検証と、実画面・実ショップ・稼働版の受入は区別する。

## 国別NG語句の出力

保安ゲートで対象国を選び、「FROMAX用NGキーワードの手動出力」のプレビューを開く。
有効な国別・共通のBLOCKルールから、貼付用TXTと注意CSVを出力する。REVIEW・無効ルールを入れない。
FROMAXには自動登録せず、既存NGブランドの設定をTXTで上書きしない。

- 貼付用TXT：部分一致へ移せる語句を1行1語にする。元表記、NFKCによる全半角正規化、ひらがな／カタカナの候補を有限に生成し重複を除く。
- 注意CSV：英語の単語境界依存、短い英語、ブランド、ASIN、完全一致等を分け、理由と出典を付ける。そのまま一括貼付しない。

FROMAXは英字の大小を区別しない部分一致であり、OTCはHotcakeにも当たり得る。
NGブランドは双方向部分一致で、KATEとKate Spadeのような別ブランドへの反応に注意する（Owner観測）。
漢字とかなの言い換えは生成せず、「湿疹」と「しっしん」を自動的に同じ語にはしない。
貼付用の日本語も否定文・注意文・付属品へ反応する可能性があり、プレビューを確認する。
今回のFROMAXリサーチ画面のNGは商品名・ブランド、AIは画像・商品名を使うというOwner観測である。
成分・説明文を本ツールへ搬送して確認する役割は残り、NGキーワードだけで保安ゲート全体を再現できるとはしない。

## 費用・比較・未採用事項

Keepaが同じキーならFROMAXと本ツールは回復トークン枠を共有する。キーの同一性を推測で確認済みにしない。
本ツールの再確認には契約トークンを消費する場合があり、両方のツールで集めた取得数と消費を区別する。
比較の停止はREVIEW／EXCLUDEとし、FROMAXの除外フラグとAI表示理由を分ける。未観測の理由を補完しない。
Owner方針では医薬部外品をSGで要確認とするため、FROMAXの一律除外だけをツールの見逃しに数えない。

カテゴリ依存のSLS正式判定は、商品資料のキーワード判定では代替保証できない。
今回確認したエアゾール等の穴への対策、注意文の「しっしん」への対策は限定修正案として扱う。
SLS不足語の大量追加、既存停止の解除、FROMAX CSV取込、実出品、自動投入、P5再開は本変更へ含めない。
PHの医薬品・医療機器（レンズ、コンドーム、検査キット、針、動物薬等）BLOCKはOwnerの全国出品除外方針であり、PHの実商品検証はPH着手時に行う。
