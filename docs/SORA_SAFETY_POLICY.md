# Sora共通保安ルール（DEC-0167）

## 現行の対象と操作

ASINの出所にかかわらず、取得済みの同じ商品資料でSG／PH／MY／TH／TWを判定する（DEC-0189）。
共通方針、選択国の規則、個別ASIN／既存Community NGを合成し、BLOCK > REVIEW > SAFEを維持する。
Gateではそれぞれ停止（EXCLUDE）、要確認（REVIEW）、通過（ELIGIBLE）へ対応する。
通過は全商品の安全・販売許可・発送適合の保証ではない。

判定ルールの変更と入口の変更は別工程である。通常画面の入口はASIN貼付とFROMAX Keepa CSVで、
最大500件、同じ入力内での手動残件再開と既出品CSVの案内を使う（DEC-0171／0172）。

MY食品の豚・酒・牛肉・家禽等は成分も照合し、食品以外には当てない。TH／TWは化粧品・食品を出さない。
国別ルールと照合名の全一覧は`NG/ledger.csv`、線引き・例外・市場状態はDEC-0189を参照する。
MY容積重量は取得済み寸法cmの積÷6000kgと実重量kgを比較し、超過は判定を変えずメモに残す。寸法・重量がない／換算・計算不能なら「サイズ情報なし」として要確認にする（DEC-0191）。
国別CSV辞書が無くても、国別ルールとCounterfeit一覧の設定済み市場では通過を出せる。
GovernanceのMY・TH・TWはINACTIVEを維持する。初版の完成対象はSG・PH・MY・THで、実出品時にOwnerが通過・要確認・停止を目視し、見逃し・止めすぎは都度の修正タスクで扱う（DEC-0193）。専用の件数・回数による完成確認は行わず、MY・THのACTIVE化はOwner指示時の別タスクとする。TWの見送りとルール保持、合成検証と実商品確認の区別を維持する。

## 設定と照合欄

| 資産 | 役割 |
|---|---|
| `guardrails/policy/rules.json` | 共通・市場別の商品語、対象欄、段階、条件、Decision参照 |
| `guardrails/deterministic_block_rules_v2.csv` | GABAの既存6表記とhempをCOMMON_BLOCKで評価 |
| `guardrails/risk_keywords_sg.csv` / `risk_keywords_ph.csv` | 共通へ移していない市場固有の既存疑義規則 |
| `guardrails/brand_monitoring/` | 公式IPR、国別Counterfeit、自社共通禁止10ブランドと承認済み別表記 |
| `guardrails/community_ng/` | 元資料の市場範囲を保持した個別ASIN・ブランドNG |
| `guardrails/sls_shared/battery_review_rules.csv` | 既存16語の電池疑義。確定BLOCKを解除しない |

DEC-0188により、`rules.json`の全ルールは必須の`scope`を持つ。
`item`（物そのもの）は商品名・カテゴリで物の種類を照合し、説明文・成分を読まない。
既存のブランド／ASIN一致ルールは元の対象欄を維持する。`content`（中身・表示）は従来の対象欄を維持し、
医薬・成分・電池・引火性・違法品等を説明文・成分も含めて照合する。一般語の説明REVIEWも`content`のままとする。
例外としてSGの動物性脂肪・きのこだけ成分欄を追加する。脂肪の成分欄は食品判定が成立する場合だけを対象とし、
商品名・説明文の`always`、きのこの`mushroom_food`は維持する。
DEC-0191では`COMMON-FIRE-FUEL`のカテゴリ一致もBLOCKにし、商品名・カテゴリに該当語がないtextだけの一致をREVIEWへ分ける。
各IDの区分は`rules.json`および自動生成した`NG/ledger.csv`／`NG/LEDGER.md`、更新手順は`NG/README.md`を正本とする。

商品名は`product_title`、説明文は`description / features / shortDescription / safetyWarning / itemHighlights`、
成分欄は`ingredients / activeIngredients / specialIngredients`を指す。説明文を成分Factへ転記しない。
Candidate固定15列、成分・文章のASIN集合／内容対応の検査、電池・家電の既存判定は維持する。
設定欠損・不正を空リストへ置換せず、判定を停止する。

| 群 | 対象・扱い |
|---|---|

「アルコールフリー」「ノンアルコール」「alcohol-free」「fake lashes」「つけまつげ」は、
該当する出現箇所を一般語照合から除外し、REVIEWにも数えない。同じ文章の別の肯定表示や別ルールは維持する。
AHA・ビタミンA等の短い英数字は境界を確認する。ハイライター、マスカラのトップコート、
食品由来成分のシャンプーなどを、燃料・ネイル・食品本体と推測しない。

DEC-0175により、「マッチャ」の中の「マッチ」とメイクアップのカテゴリにおける明確なワイン色名は、
該当箇所だけを除く。DEC-0188で香水ルールはitemとなり、香水に関する説明文は全て対象外とする。
商品名・カテゴリに香水・フレグランス等がある本体、content側の酒類・マッチ等は停止を維持する。

DEC-0179／0180の衣料用洗剤・柔軟剤／柔軟仕上げ剤／fabric softenerは、DEC-0188により商品名・カテゴリだけで照合する。
Amazonカテゴリの「洗濯・仕上げ剤」階層を共通BLOCKにする。この階層は洗剤・柔軟剤・漂白剤・洗濯のり等を含む。
食器用洗剤はその名前だけでは洗濯用と扱わず、共有の末端名「液体洗剤」だけではBLOCKしない。
サプリ・健康食品とアダルトの具体的なカテゴリ、傷あと・術後ケアやシリコーンジェルシートも共通BLOCKとする。
非医療用テープや広い衛生用品カテゴリはこれだけでは停止しない（普通のばんそうこうはDEC-0182で停止に変更）。
上位カテゴリや本文が取得されていなければ、存在しない情報を推測して検出成功としない。

コロンの明確な表記は商品名・カテゴリで香水と同様にBLOCKし、コロンビア・丸い形の「コロンと」・
セミコロン・コロン記号という別語は除く。香水の香りを例える表現と、商品名にシャンプー・洗浄用品・柔軟剤を明示した
商品のフレグランス表示だけを限定して区別し、香水・コロン本体や独立した肯定表示の停止を維持する。
柔軟剤に当たる場合は、フレグランス表示の除外にかかわらず柔軟剤としてBLOCKする。
成分の並び順だけによる引火性の独立BLOCKは行わない。液体と確認できる商品の「火気注意」「火気厳禁」「引火性」はBLOCKし、
液体か確認できない既存のエアゾール疑義は従来のREVIEWを維持する。別のBLOCKは常に優先する。

「株式会社」の中の「株式」は照合から除くが、別に記載された株式は止める。
「ギャバ」は既存の商品名・成分欄では「ギャバン」「ギャバリオン」の一部であっても共通BLOCKとする。
おもちゃの具体的なカテゴリでは、歯ブラシ・コイン・牛乳のおもちゃ付属品語だけを除き、電池などの別理由は維持する。
爪切り・爪やすり等の道具における一般的なネイル語、化粧品の和漢植物成分、ヘアカラーラスティングや
「ヘアカラーの色落ち」「カラーリング後」の髪色保護への言及、
食洗機用洗剤、入浴剤の「食添→特号→肥料」の等級説明も各該当箇所に限って区別する。
マニキュア・染毛剤・植物本体・家電本体・肥料本体等の別の肯定表示は維持する。
PH／SGの既存Community NG「エーザイ」に、Owner指定の英字ブランド欄完全一致 `Eisai` を加える。
公式IPRへの追加ではなく、その他の公式ブランドと国別範囲は変更しない。

DEC-0168により、SGのお守りと共通の植物語は商品名・カテゴリだけを照合する。
DEC-0170により「種子」も商品名・カテゴリだけとし、種子油／種子エキス／種子オイルは除外する。
園芸用土・生体・英語のseeds等も、DEC-0188により商品名・カテゴリだけを照合する。
「お守りください／お守り下さい」「植物由来／植物性／植物エキス／植物オイル／植物アロマ」は
該当箇所だけを除き、別のお守り・観葉植物等の商品表示を解除しない。
カタカナ直後の「アルコール」は複合成分名として除外するが、独立した「アルコール度数」等は従来どおり判定する。
コンタクトレンズを外す・着用者への注意書きは、明確な指示の該当箇所だけを除き、別の肯定表示を維持する。
漂白剤はDEC-0188のitemとなり、注意書き・説明文だけでは照合しない。商品名の漂白剤と、
content側の過酸化水素等の酸化剤成分、他の独立した停止は維持する。

DEC-0169により、descriptionを含む文章5欄でも「全成分／成分／原材料」等の見出しと一覧の書式を
確認できる区間だけを成分一覧として区別する。新規成分NG群の全語に同じ区間判定を適用する。
改行やHTMLの区切りごとに一覧の書式を確認し、段落末・別見出し・通常文への切替で区間を閉じる。見出しを別項目へ持ち越さない。
見出しがない、不正、区間を確認できない場合はBLOCKを維持する。商品名や区間外の通常説明・効能表示はBLOCKとし、
同じ語が一覧の内外にある場合もBLOCKを優先する。医薬部外品表示、ジフェンヒドラミン等の既存停止は降格しない。
判定メモには照合欄と、該当した語の前後20文字程度を添える。

## ブランド

主要ブランド名の完全一致、全半角・大小・アクセント・空白／中点／長音の既存正規化、括弧外優先を維持する。
Owner承認済みの別表記は既存36件に41件を加えた77件。ミルボン→Milbon、ポケモン→PokemonはSGにだけ効く。
別表記の追加は参照先の国別範囲を広げない。インテグレート、KATE、エリクシールを親会社名から停止しない。

DEC-0170により、商品のブランド欄と一致しない公式IPR／当該国Counterfeitのブランド・キャラクター・IP名が
商品名にあればREVIEWとする。ブランド欄が一致する既存BLOCK、別のBLOCK優先は維持する。
`guardrails/brand_monitoring/title_review.json`の`company_names`は商品名照合だけの会社名除外で、初期値はKao／花王。
同じ会社の承認別名にも除外を適用するが、ブランド欄のBLOCKは解除しない。会社・親子関係を自動推定しない。
英字は単語境界を確認する。`ambiguous_names`の一般語・色名（ブラウン等）と短い英字1〜3文字は、
単なる出現で要確認にせず「ブランド:」や登録商標記号等の明示がある場合だけ扱う。単語間をまたいで別名を作らない。
設定欠損・不正で照合なしの通過へ戻さない。自社禁止ブランドだけの一覧を商品名照合へ広げない。

Louis Vuitton、Gucci、Chanel、Hermes、Prada、Rolex、Cartier、Tiffany、Burberry、Diorを
自社共通禁止として扱う。Tiffany & Co、Christian Diorも同じ自社方針の表記として保持する。
公式IPR／Counterfeitを書き換えて自社方針を公式禁止に見せない。
承認済みのプラダ、ロレックス、ティファニーは共通自社方針を参照する。

## SLS表とAmazonカテゴリの境界

Owner提供2026-09-17版CSVはsource-lock masterのSHA-256
`35f7bab5da9c5dd3d9b62456035916a9fce62a153d6bcfcaa82c221dc117dbc9`と一致する。
SGのNO 171件、PHのNO 174件を、元の市場範囲付きの具体的な禁止商品群の根拠にする。

商品語とAmazonカテゴリの具体的ノード／完全パスの一致は、商品群を識別する保安の手がかりとして使う。
「ヘアケア・カラー・スタイリング」全体をヘアカラーと扱わない。`Others`単独、広い`Health`だけでは止めない。

SGの食品63カテゴリの5kg未満、PH17カテゴリの1〜2個は注文数量判定と切り離し、表示は後続の入口工程で扱う。
